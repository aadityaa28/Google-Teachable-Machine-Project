# Teachable Machine Project

## About

This project is a machine learning model created using Google Teachable Machine.

The model was trained to recognize different objects using image-based classification. Images were collected for each class, used to train the model, and then tested to check its predictions.

The project demonstrates the basic workflow of collecting data, training a machine learning model, and testing its performance.
